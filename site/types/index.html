Типы велосипедов

Чем отличаются шоссейные, горные, городские и другие велосипеды, для чего каждый подходит и как за ним ухаживать.

Шоссейный велосипед

Лёгкий и быстрый велосипед для асфальта с рулём-«бараном» и узкими шинами.

Горный велосипед (МТБ)

Велосипед для бездорожья: широкие шины, подвеска, мощные тормоза.

Гравийный велосипед (грэвел)

Велосипед с рулём-«бараном» для грунтовок, гравия и дальних поездок.

Городской велосипед

Удобный велосипед для поездок по городу с прямой посадкой, крыльями и багажником.

Японский городской велосипед «мамачари»

Японский городской велосипед для повседневных дел: корзина, подножка, кожух цепи, часто — электропривод.

Гибрид (фитнес-велосипед)

Нечто среднее между шоссейным и горным: прямой руль и быстрые колёса 700C.

Туристический велосипед

Прочный велосипед для дальних путешествий с багажом.

BMX

Маленький прочный велосипед на 20-дюймовых колёсах для трюков и гонок.

Складной велосипед

Велосипед, который складывается для перевозки в транспорте и хранения.

Электровелосипед

Велосипед с электромотором, помогающим при педалировании.

Фэтбайк

Велосипед с очень широкими шинами (около 4–5") для снега и песка.

Трековый велосипед и фикс

Велосипед с одной «глухой» передачей, без свободного хода.

Тандем

Велосипед для двоих: капитан управляет, второй (стокер) крутит педали.

Грузовой велосипед

Велосипед для перевозки детей и грузов: с коробом впереди или удлинённым багажником.

Детские велосипеды и беговелы

От беговела без педалей до подросткового велосипеда на колёсах 24".
